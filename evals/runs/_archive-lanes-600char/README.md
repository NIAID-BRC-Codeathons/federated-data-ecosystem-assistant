# Archived: the first BOBBY-LANES attempt, cut at 600 characters

Launched 15:52, stopped 16:0x at about 60 of 560 transcripts. **Not deleted, and
not comparable to the run that replaced it.**

Every tool result here is truncated at `RESULT_EXCERPT = 600`. Measured across
366 real results, the median is 1,621 characters, so more than half of a typical
result is missing and only 15% survived whole. The judge's
`retrieved_not_reported` check needs a total and a returned count visible in the
same result, and 146 of 344 results were cut before that pair became legible.

The replacement run uses 4000, which keeps 68% whole.

**Do not mix these with the new transcripts**, and do not score them. They are
kept because a stopped run is still the evidence for why it was stopped — and
because clearing a directory another agent was reading has already destroyed one
set of transcripts on this project.
